Règles de confidentialité

Aerith est une application personnelle et privée : son seul utilisateur est son propriétaire, qui l'utilise avec ses propres comptes Google.

  • Données utilisées : les mails, l'agenda, les contacts et les fichiers Drive du propriétaire, uniquement pour l'aider au quotidien (résumés, rangement des mails, rendez-vous).
  • Partage : aucune donnée n'est vendue, partagée ni transmise à des tiers, et aucune n'est utilisée pour entraîner un modèle d'IA.
  • Conservation : les données restent sur l'ordinateur du propriétaire ; seules de courtes notes de travail sont conservées, le temps nécessaire.
  • Retrait de l'accès : l'accès peut être retiré à tout moment depuis myaccount.google.com/permissions.

L'utilisation des données reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).
